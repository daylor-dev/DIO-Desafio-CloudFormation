

\# Desafio AWS DIO: CloudFormation



\## Sobre CloudFormation



A CloudFormation é uma ferramenta da AWS usada para criar templates que são reutilizáveis, ou seja, é possível replicar um mesmo template sempre que necessário.



Nesse template, conhecido como stack ou pilha (em português), vários recursos podem ser criados em um curto período de tempo e de forma programática e automatizada.
